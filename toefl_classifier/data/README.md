# Data Directory

This directory is used to store data files for the TOEFL vocabulary classifier project.

## Expected Contents

- **Raw vocabulary files**: TOEFL word lists and vocabulary data
- **Processed data**: Filtered and classified vocabulary
- **Output files**: Generated word lists and statistics

## Notes

- Place your raw TOEFL vocabulary files in this directory
- Processed outputs will be stored here by the classifier scripts
- This directory is ignored by git (see .gitignore in root)
